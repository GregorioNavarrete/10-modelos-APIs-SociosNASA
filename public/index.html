1 · Proxy con caché

Cada app consulta al servidor Express, que normaliza la API, cachea y evita CORS. Las claves opcionales viven en .env, nunca en el repositorio.

2 · Respaldo declarado

Si una API pide registro o se cae, la interfaz muestra el subset de data/respaldo/ y lo indica en pantalla. La demo nunca queda vacía.

3 · Modelo y límites

Cada solapa 1 explica el problema, el usuario y la sostenibilidad. Cada solapa 2 declara licencias, límites y qué se puede construir después.
