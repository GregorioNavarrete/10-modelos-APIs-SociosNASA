Cómo se calcula

S = Σ sign(xj − xi)  para j > i
Var(S) = n(n−1)(2n+5)/18
Z = (S ∓ 1) / √Var(S)
p = 2 · (1 − Φ(|Z|))
tau = S / (n(n−1)/2)
Sen = mediana( (xj − xi) / (j − i) )

La pendiente de Sen se multiplica por 10 para expresar mm/década. El p-valor usa la aproximación normal, válida para n ≥ 8.

Qué más se puede pedir

  • IMERG (GES DISC): lluvia cada 30 min y 0,1°; ideal para eventos extremos.
  • MERRA-2: viento, humedad, radiación y temperatura con consistencia física.
  • ESA CCI Soil Moisture: humedad de suelo de 40 años.
  • GSMaP: lluvia global con cobertura casi horaria.
  • CHIRPS: lluvia diaria 0,05° para validar.

Alcance y advertencias

Resolución: POWER representa celdas de ~50 km, no un lote. No sirve para decisiones prediales.

Estadística: con 10-11 años, la potencia del test es baja; un p > 0,05 no prueba ausencia de tendencia.

Datos: POWER es un reanálisis/modelo, no una estación. Para ingeniería, validar con observaciones locales.
